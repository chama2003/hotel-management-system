# LuxStay — Hotel Management System (Laravel)

A full-stack hotel management system: public room catalog, a multi-step booking
engine with live availability checking, mock/sandbox payments with PDF invoices,
a guest dashboard, a staff front-desk console, and an admin panel with
analytics and CSV export. Built on Laravel 11 (PHP 8.2+), Blade, Tailwind CSS
(via CDN) and Alpine.js.

> **This archive contains the application source only** (`app/`, `database/`,
> `resources/views`, `routes/`, `config/booking.php`, `bootstrap/app.php`,
> `composer.json`, `.env.example`). It does **not** include the Laravel
> framework skeleton itself (`vendor/`, `public/index.php`, `artisan`, the
> default `bootstrap/`, `config/*.php`, etc.) — those are generated by
> Composer, not hand-written, so you lay this code on top of a fresh Laravel
> install rather than unzip-and-run. Setup below takes about five minutes.

---

## 1. Requirements

- PHP 8.2+ with the usual extensions (`pdo_mysql`, `mbstring`, `openssl`, `gd`, `zip`)
- Composer 2
- MySQL 8 (or MariaDB 10.6+)
- Node.js is **not** required — Tailwind/Alpine/Chart.js/FontAwesome load from CDN in `resources/views/layouts/app.blade.php`. Swap for a local Vite build if you prefer offline assets.

## 2. Setup

```bash
# 1. Scaffold a fresh Laravel 11 app (pulls the framework + vendor/ from Packagist)
composer create-project laravel/laravel hotel-management-system "^11.0"
cd hotel-management-system

# 2. Copy this project's source on top of the fresh skeleton, overwriting
#    the default routes/web.php and bootstrap/app.php
cp -R /path/to/this-archive/app/.        ./app/
cp -R /path/to/this-archive/database/.   ./database/
cp -R /path/to/this-archive/resources/.  ./resources/
cp    /path/to/this-archive/routes/web.php     ./routes/web.php
cp    /path/to/this-archive/routes/console.php ./routes/console.php
cp    /path/to/this-archive/bootstrap/app.php  ./bootstrap/app.php
cp    /path/to/this-archive/config/booking.php ./config/booking.php

# 3. Add the two extra packages this project uses (PDF invoices + CSV/Excel export)
composer require barryvdh/laravel-dompdf maatwebsite/excel

# 4. Environment
cp /path/to/this-archive/.env.example .env   # or hand-edit the one create-project made
php artisan key:generate

# 5. Create a MySQL database, then set DB_* in .env to match, e.g.:
#    DB_DATABASE=hotel_management  DB_USERNAME=root  DB_PASSWORD=

# 6. Migrate + seed demo data (admin/staff/guest accounts, amenities, 6 rooms)
php artisan migrate --seed

# 7. Serve it
php artisan serve
# → http://127.0.0.1:8000
```

## 3. Architecture

Standard Laravel MVC, organized by role:

```
app/
  Models/          User, Room, Amenity, RoomImage, RoomStatusLog, Booking, Payment, Invoice
  Http/
    Controllers/
      RoomController.php          # public catalog + detail page
      BookingController.php       # multi-step booking engine, availability API, cancel, PDF invoice
      Auth/                       # register / login / logout
      Customer/DashboardController.php
      Staff/FrontDeskController.php
      Admin/RoomManagementController.php
      Admin/UserManagementController.php
      Admin/AnalyticsController.php   # dashboard metrics + CSV export
    Middleware/RoleMiddleware.php     # role:admin / role:staff,admin / etc.
database/
  migrations/      users, rooms, amenities (+pivot), room_images, room_status_logs,
                   bookings, payments, invoices
  seeders/         UserSeeder, AmenitySeeder, RoomSeeder
resources/views/   Blade + Tailwind, organized by area (rooms, bookings, customer, staff, admin)
routes/web.php     Route groups gated by the `role` middleware
config/booking.php Cancellation window + tax rate + payment gateway mode
```

### Role-Based Access Control

`app/Http/Middleware/RoleMiddleware.php` is registered as the `role` alias in
`bootstrap/app.php`. Routes are grouped and gated in `routes/web.php`, e.g.:

```php
Route::prefix('admin')->middleware('role:admin')->group(...);
Route::prefix('staff')->middleware('role:staff,admin')->group(...);
```

Public self-registration (`/register`) always creates a `customer` account —
Staff and Admin accounts can only be provisioned by an existing Admin, from
**Admin → Users → Add Staff/Admin**.

### Double-booking prevention

`Room::isRoomAvailable()` checks for any existing booking in `pending`,
`confirmed`, or `checked_in` status whose date range overlaps the requested
one (`existing.check_in < newCheckOut AND existing.check_out > newCheckIn`).
This is checked **twice**: once for the live availability widget
(`GET /rooms/{room}/availability`, called by Alpine as the guest picks dates),
and again inside the `DB::transaction()` in `BookingController@store` right
before the booking is written, to close the race condition between page load
and form submission.

### Payments & invoices

`config/booking.php` defaults `payment_gateway` to `mock` — no external network
call is made. Guests choose "Pay now (sandbox card)" or "Cash on Arrival" at
checkout; the mock flow simply marks the `payments` row `paid` and confirms
the booking instantly, so you can see the whole flow end-to-end with zero
external setup. To integrate real Stripe: set `STRIPE_KEY`/`STRIPE_SECRET`
in `.env`, then replace the `mock_card` branch in
`BookingController@store` with a real `PaymentIntent` call.

A PDF invoice (via `barryvdh/laravel-dompdf`, view:
`resources/views/bookings/invoice-pdf.blade.php`) is generated on every
successful booking and downloadable from the confirmation page or the
guest's booking history at any time.

### Analytics & export

`Admin\AnalyticsController@index` computes total revenue, live occupancy
rate, monthly booking/revenue trend (rendered with Chart.js from CDN) and a
room-type breakdown. `@exportCsv` streams a CSV of bookings for a date range,
which opens directly in Excel/Sheets — no extra dependency required for that
particular export, though `maatwebsite/excel` is included in `composer.json`
if you'd rather generate a native `.xlsx`.

## 4. Extending this further

- **File uploads for room photos**: `room_images.path` currently expects a URL (seeded with Unsplash images); wire up `Storage::disk('public')` + `php artisan storage:link` and a file input in `admin/rooms/_form.blade.php` to accept real uploads.
- **Real payment gateway**: swap the mock branch described above.
- **Email notifications**: hook `Illuminate\Auth\Events\Registered` and booking confirmation/cancellation into Laravel Notifications (Mailable classes) — `MAIL_MAILER=log` in `.env.example` is a safe default for local dev.
- **Tests**: none are included in this drop; `Room::isRoomAvailable()` and the `BookingController@store` overlap re-check are the highest-value places to start with Pest/PHPUnit feature tests.
